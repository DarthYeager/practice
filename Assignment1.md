## Questions 

1.
    Write a Python program that displays a welcome message and the current course name on separate lines.
2.
    Create variables for a student's name, roll number, course and percentage. Display them using f-strings.
3.
    Accept an integer from the user and display its value in decimal, binary, octal and hexadecimal formats.
4.
    Create variables using integer, float, string and Boolean literals. Display each value and its data type.
5.
    Build a simple asset card that accepts an asset ID, device name, owner and location, then prints a neatly formatted report.
6.
    Accept two numbers and display their sum, difference, product, quotient and remainder.
7.
    Accept length and width and calculate the area and perimeter of a rectangle.
8.
    Accept temperature in Celsius and convert it to Fahrenheit and Kelvin.
9.
    Accept a user's name and age, then print a sentence using f-string formatting with aligned fields.
10.
    Demonstrate the difference between integer division and floating-point division using user-supplied values.
11.
    Accept a number as text, convert it to an integer and display its square. Handle an invalid numeric entry by asking the user to try again.
12.
    Create two variables, assign one to the other, modify one variable and display the results. Repeat with a mutable list and explain the observed difference in comments.
13.
    Write a program that calculates simple interest from principal, rate and time entered by the user.
14.
    Accept a number of seconds and convert it into hours, minutes and seconds.
15.
    Accept marks in five subjects and calculate total, average and percentage.
16.
    Write a subnet calculator for an IPv4 address and prefix length using Python's ipaddress module. Display the network address, broadcast address and number of usable hosts.
17.
    Accept an amount in rupees and calculate the value after applying a user-entered percentage discount.
18.
    Create a small menu-driven calculator for addition, subtraction, multiplication and division.
19.
    Accept a distance in kilometres and convert it into metres, centimetres and miles.
20.
    Create a formatted report containing a student's details, marks, average and pass/fail status using only local input and basic Python operations.
